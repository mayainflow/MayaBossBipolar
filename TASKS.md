## Решено: оплата платной методички

CONTENT_MASTER.md/FAQ/LEGAL_TEXTS.md описывают реальную покупку методички №2 (50₪), а
SITE_PRD.md разделы 5/19 по-прежнему исключают онлайн-оплату из v1.0. Решение владельца:
на странице методички — форма заявки на покупку (имя + контакт), она приходит Майе как заявка,
дальше она сама связывается с человеком по поводу оплаты вручную. Реализовано:
`PurchaseRequestForm` → `/api/purchase-request`. Реальный платёжный провайдер — не в v1.0.

## Технические заметки для следующего шага

**Фото.** Реальные загруженные файлы, согласно CONTENT_MASTER.md: `avatar.jpg`, `cover.png`,
`lecture_offline.jpg`. Другие имена, встречавшиеся в более ранних версиях документа, не
существуют и удалены из кода. Сами файлы на сайт ещё не попали (это по-прежнему просто текстовые
описания) — их нужно положить в `public/images/<имя>`, тогда `PhotoFrame` подхватит их
автоматически.

**Методички.** Обложки/PDF ещё не загружены — `MaterialCover` подхватит
`public/materials/covers/<slug>.jpg` автоматически; сами PDF ожидаются в `public/materials/` под
именами из `src/lib/materials.ts`.

**Email/интеграции** — нужен рабочий `RESEND_API_KEY` (аккаунт Resend или другой провайдер),
Measurement ID для Google Analytics, Pixel ID для Meta Pixel.

**Логотип/favicon** — используется временный favicon Next.js по умолчанию; нужен файл монограммы
(SVG/PNG) для замены.

**Instagram** — ссылка пока не прислана (CONTENT_MASTER.md).
