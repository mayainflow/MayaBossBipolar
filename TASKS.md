## Технические заметки для следующего шага

**Не хватает файлов изображений.** В чате были показаны фото (аватар "два полюса", обложка Facebook, офлайн-лекция), но как файлы на диск они не попали — только 4 .md файла. Компонент `PhotoFrame` уже настроен: если положить файл в `public/images/<имя>.jpg` с именем из CONTENT_MASTER.md (`lecture_offline.jpg`, `lecture_offline_2.jpg`, `lecture_offline_3.jpg`, `lecture_presentation.jpg`, `clown_nursing_home.jpg`, `award.jpg`, `tattoo_symbol.jpg`), фото появится на сайте автоматически, без правок кода.

**Не хватает данных для контактов и интеграций** — см. `src/lib/site-config.ts` (email, соцсети) и переменные окружения `RESEND_API_KEY`/`CONTACT_TO_EMAIL` (или другой email-провайдер).

**Методички:** цена и статус (платная/бесплатная) не подтверждены — на сайте показана пометка «стоимость уточняется». Сами PDF и обложки не загружены — компонент `MaterialCover` подхватит `public/materials/covers/<slug>.jpg` автоматически, когда файл появится; сами PDF ожидаются в `public/materials/` под именами из `src/lib/materials.ts` (`50_pravil.pdf`, `metodichka_2_tehniki.pdf`).

**Логотип/favicon** — используется временный favicon Next.js по умолчанию; нужен файл монограммы (SVG/PNG) для замены.
