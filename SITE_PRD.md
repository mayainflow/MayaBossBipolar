## 1. Видение проекта (Vision)

Создать современный сайт личного бренда Майи Штейнберг «Я Босс Моей Биполярки», который одновременно:

- вызывает доверие;
- рассказывает историю Майи;
- объясняет философию проекта;
- позволяет записаться на лекцию;
- продаёт методички;
- становится центральной точкой всех социальных сетей.

Сайт не является интернет-магазином. Не является медицинским порталом. Не является блогом в классическом понимании.

Главная задача сайта — познакомить человека с Майей, дать ощущение надежды и привести его к следующему шагу: регистрации на лекцию, покупке методички или подписке на Telegram.

### Что сайт НЕ должен делать

Сайт не должен выглядеть как:

- сайт психиатрической клиники;
- сайт медицинского центра;
- сайт, где пугают диагнозами;
- сайт «успешного успешника»;
- сайт инфобизнеса с криками «Купи сейчас».

Запрещено:

- обещать излечение;
- давать медицинские рекомендации вместо врача;
- использовать манипулятивные продажи;
- перегружать страницу анимацией;
- использовать агрессивные всплывающие окна;
- публиковать непроверенные медицинские факты.

### Главная эмоция

Сайт должен производить впечатление спокойствия. Не драмы, не болезни, не жалости.

Посетитель должен чувствовать: безопасность, уважение, тепло, искренность, ощущение «Меня здесь понимают».

---

## 2. Основная идея

После посещения сайта человек должен подумать:

> «Если она смогла пройти через всё это и сегодня живёт полной жизнью, возможно, и у меня получится».

Именно это чувство должно оставаться после просмотра. Не жалость, не страх, не ощущение болезни — а надежда.

---

## 3. Целевая аудитория

**Основная:** люди с биполярным расстройством, 25–65 лет, большинство — женщины. Многие только получили диагноз, многие в депрессии. Часть родственников ищет информацию вместо самого человека.

**Вторичная:** родственники — муж, жена, дети, родители, друзья. Приходят с вопросом «Как помочь близкому человеку?»

**Третья:** психологи, социальные работники, сотрудники реабилитации, организаторы лекций, журналисты.

---

## 4. Главный сценарий пользователя

Человек приходит из Instagram, ничего не знает о Майе. Через 15–20 секунд на сайте он должен понять:

- кто такая Майя;
- почему ей можно доверять;
- чем она занимается;
- что можно сделать прямо сейчас.

Далее выбирает один из путей:

1. Записаться на лекцию.
2. Купить методичку.
3. Подписаться на Telegram.
4. Посмотреть историю Майи.
5. Связаться для приглашения на выступление.

Если действие не совершено — сайт всё равно должен оставить ощущение доверия, чтобы человек вернулся позже.

## 5. Архитектура сайта

Утверждённая структура (v1.0 с заделом под v5.0 — новые разделы добавляются, не ломая существующее):

```
Главная
  ↓

  ↓

  ↓
Блог → Статьи / Видео
  ↓
FAQ
  ↓
Обо мне
  ↓
Контакты
  ↓
MyBalance (будущий раздел, НЕ входит в v1.0)
```

### Что входит в первую версию (v1.0)

Главная (Hero, Кто я, О лекциях, Методички, Отзывы, FAQ, Контакты), плюс отдельные страницы: Лекции, Методички, Блог, FAQ, Контакты.

### Что НЕ входит в v1.0

Личный кабинет, регистрация пользователей, форум, комментарии, онлайн-чат, интернет-магазин, система оплаты, календарь мероприятий, мобильное приложение, MyBalance, личный дневник настроения. Эти функции рассматриваются после успешного запуска v1.0.

## 9. Дизайн-система и технические требования

> ✅ Черновик дизайн-дефолта собран на основе аватара и обложки Facebook (11.07.2026). Не финальный брендбук, но достаточно, чтобы Claude Code не изобретал вслепую. Точные hex-коды — уточнить пипеткой по исходникам при вёрстке.

### Концепция: «Два полюса. Одна я.»

Визуальный язык уже задан существующими материалами: лицо/бренд разделены на холодную (депрессия/ночь) и тёплую (подъём/солнце) стороны. Это и есть визуальная метафора биполярного расстройства — используем её как основу дизайн-системы, а не придумываем новую.

### Палитра

**Холодная сторона (депрессия / ночь):**
- Глубокий тёмно-синий / индиго (фон обложки, ночное небо) — базовый тёмный тон
- Серебристо-голубой (молния, лёд) — акцент

**Тёплая сторона (подъём / солнце):**
- Золото / янтарь (молния-логотип, закат)
- Оранжево-розовый / коралловый (фейерверк, закат)

**Нейтральные (для основного UI — текст, карточки, фон страниц):**
- Тёплый белый / светло-серый фон (не чисто белый — мягче)
- Тёмно-серый / почти чёрный для текста

### Правило использования цвета

Яркий дуо-тон (золото + индиго/синий) — для: логотипа, Hero-секции Главной, кнопок основного CTA, акцентных линий-разделителей.

Спокойный нейтральный фон — для: основного текста, карточек методичек/статей, форм, FAQ. **Не заливать весь сайт градиентом с обложки** — это перегрузит страницы и войдёт в противоречие с принципом "спокойствие" (раздел 1).

### Типографика

- Заголовки / имя бренда — рукописный / каллиграфический шрифт (как "Maya Steinberg" на обложке) — точечно, для акцентов (Hero, подписи), не для основного текста.
- Подзаголовки и лозунги ("Я БОСС МОЕЙ БИПОЛЯРКИ") — чистый sans-serif, широкий трекинг, заглавные.
- Основной текст сайта (статьи, описания) — простой читаемый sans-serif, без засечек, обычный трекинг.

### Логотип

Монограмма (буквы + молния, разделённая на золотую/синюю половины) уже существует на обложке — использовать как основной логотип/фавикон.

### Фото и изображения

Аватар (боди-арт "два полюса лица") — сильный образ для Hero или страницы "Обо мне", но не для каждой страницы подряд — иначе теряет силу. Дополнить обычными "живыми" фото (лекции, клоунада), как уже отмечено в разделе 7.

### Технический стек и требования (принципы, не финальный TECH.md)

- Mobile-first.
- Минимум кастомных шрифтов (2 семейства максимум: акцентный рукописный + основной sans-serif).
- Минимум тяжёлых анимаций/видео на первом экране (раздел 21 PRD).
- Полноценный TECH.md (фреймворк, структура папок, деплой-пайплайн) — можно оставить на усмотрение Claude Code в момент старта, если специальных требований нет.

## 10. Страница «Лекции»

### Назначение

Для двух категорий посетителей: (1) кто хочет прийти на лекцию, (2) организации, желающие пригласить Майю выступить.

Страница отвечает на вопросы: о чём лекция, для кого, что получит участник, как записаться, как пригласить.

### Структура страницы

1. Заголовок
2. Краткое описание
3. Для кого лекция
4. Основные темы
5. Форматы проведения
6. Частые вопросы
7. Форма записи
8. Форма приглашения

### Заголовок

**Я Босс Моей Биполярки**
Подзаголовок: Честный разговор о жизни с биполярным расстройством — без запугивания, без романтизации, с уважением к каждому человеку.

### Основные темы

- путь от первых симптомов до сегодняшнего дня;
- как выглядит жизнь с БАР изнутри;
- что реально помогает сохранять стабильность;
- ошибки, которые были совершены;
- поддержка близких;
- ответы на вопросы участников.

### Форматы

Онлайн (Zoom), офлайн, домашние встречи, выступления для организаций.

### Продолжительность

60–90 минут, при необходимости адаптируется под запрос организатора.

### CTA

[Записаться на ближайшую лекцию]  [Пригласить Майю выступить]

Обложка, название, 2–3 предложения описания, для кого предназначена, количество страниц, кнопка «Подробнее».

## 12. Страница «Блог»

### Назначение

Повышать доверие и помогать находить сайт через поисковые системы. Не личный дневник — библиотека полезных материалов.

### Категории

Личный опыт, практические техники, жизнь с БАР, для родственников, новости проекта, лекции.

### Каждая статья содержит

Заголовок, дату публикации, время чтения, основной текст, блок «Что можно сделать уже сегодня», ссылки на связанные материалы, призыв записаться на лекцию или посмотреть методички (если уместно).

## 15. Навигация

Человек никогда не должен задумываться «куда теперь нажать» — навигация должна быть очевидной.

**Верхнее меню:** Логотип · Главная · О Майе · Лекции · Методички · Блог · FAQ · Контакты · кнопка «Записаться». При прокрутке остаётся сверху, высота уменьшается ~15%. Без исчезающих меню.

**Нижнее меню:** повторяет основные разделы + Политика конфиденциальности, Условия использования, Медицинский дисклеймер.

## 18. Формы

Все формы максимально короткие — чем меньше полей, тем выше вероятность заполнения.

**Запись на лекцию:** Имя*, Телефон*, Email, Комментарий → [Записаться]

**Приглашение выступить:** Имя, Организация, Телефон, Email, Город, Комментарий

**Обратная связь:** Имя, Email, Сообщение

После отправки: страница не перезагружается, появляется сообщение об успешной отправке.

## 21. Производительность

## 22. Обработка ошибок

**Страница 404:** «Похоже, эта страница потерялась. Давайте вернёмся туда, где можно найти что-то полезное.» → кнопка [На главную]

**Ошибка отправки формы:** «Не удалось отправить сообщение. Попробуйте ещё раз через несколько минут или напишите мне напрямую.» (не показывать технические коды ошибок)

## 23. Медицинский дисклеймер

Сайт не оказывает медицинских услуг. Материалы проекта основаны на личном опыте Майи Штейнберг и предназначены для информационной поддержки. Любые вопросы лечения, изменения дозировок препаратов или отмены терапии необходимо обсуждать только с лечащим психиатром. Если человек находится в кризисном состоянии или чувствует непосредственную опасность для себя, необходимо обратиться за экстренной медицинской помощью.
